# 礼林生态官网标志

官网标志采用现代印记的正式图形，保持原有路径、开口及图文比例。

- 主色：`#36593E`，与官网按钮和链接一致。
- 底色：`#F8F7F3`；透明底横版用于顶部及页脚。
- 浏览器图标：米白底绿色印记，提供 SVG、32px PNG 和 48px ICO。
- 主屏幕图标：绿色底米白印记，180px PNG。
- 分享图：1200 × 630px，米白底，包含标志、品牌名称及“善心 · 善念 · 善行”。

`logo-horizontal-green.svg` 为可编辑横版，`symbol-green.svg` 为独立图形。网站实际使用已栅格化的横版 PNG，保证各设备上的中文字形一致。SVG 字标采用微软雅黑（中文 600 字重，英文 400 字重）。

导出源位于 `scripts/generate-brand-assets.mjs`。在安装微软雅黑及项目依赖的环境中运行 `node scripts/generate-brand-assets.mjs` 可重新生成文件。生成文件已纳入版本管理，网站部署无需安装字体或重新导出。
